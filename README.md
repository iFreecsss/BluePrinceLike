# Projet BluePrince-like, ROB

Ce projet implemente le game loop principale du jeu "BluePrince" de façon simpliée en 2D en utilisant Pygames.
On peut placer des salles, collecter des objets, intéragir avec des coffres, des lockers, des trous.
La condition de victoire est d'atteindre l'Antechambre en haut de la carte en sans atteindre 0 pas.

## Prérequis

- Python 3
- pip

## Installation

1. Cloner le dépôt
    ```sh
    git clone https://github.com/iFreecsss/BluePrinceLike
    ```

2. Créer un environnement virtuel
    ```sh
    python -m venv env
    source env/bin/activate  # Mac/Linux
    env\Scripts\activate     # Windows
    ```
3. Installer les dépendances
    ```sh
    pip install -r requirements.txt
    ```


## Utilisation

```sh
python main.py
```
